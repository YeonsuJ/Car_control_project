# 프로젝트 초기 계획

## 프로젝트 명 : 핸들링 모션 기반 RC카 네트워크 시스템

## 아이디어 도출과정 및 프로젝트 목표

현재 RC카 시장의 조종기는 대부분 조이스틱 혹은 건(Gun) 타입이며, 이는 실제 차량의 스티어링 휠 기반 조작 방식과 큰 차이를 보인다. 동시에, 실제 자동차 산업에서는 CAN(Controller Area Network) 통신이 차량 내 전자 장치 간의 데이터 교환을 위한 표준 네트워크로 자리 잡았으나, 취미용 RC카 분야에서는 이러한 전문적인 네트워크 기술이 거의 적용되지 않고 있다.

기존 RC카의 비직관적인 조종 방식에 아쉬움을 느꼈고, 실제 운전과 같은 실감 나는 경험을 제공하고 싶다는 생각을 갖게 되었다. 또한, 단순한 RC카 시스템을 만드는 것을 넘어, 실제 자동차 산업 현장에서 사용되는 CAN 통신과 RTOS(실시간 운영체제) 기술을 직접 적용하며 완성도 높은 임베디드 시스템을 RC카에 구현하고 싶었다.

이를 위해 다음과 같은 핵심 목표를 설정하였다.

- `직관적인 모션 컨트롤러 구현` : 실제 핸들링 모션을 IMU 센서로 정밀하게 수집 및 처리하고, 안정적인 RF 통신을 통해 RC카에 실시간으로 조향 명령을 전달한다.

- `CAN 기반 분산 제어 시스템 구축` : 차량의 제어부를 기능별 노드(ECU)로 분리하고 이를 CAN 통신으로 연결하여, 데이터 수집 및 명령 전달이 가능한 통합 네트워크 시스템을 구현한다.

- `양방향 원격 측정(Telemetry) 기능 구현` : 컨트롤러와 차량 간 양방향 무선 통신 네트워크를 구성하여, 차량의 센서 데이터(충돌 경고 신호, 속력 등)를 컨트롤러로 실시간 전송하고 사용자에게 피드백한다.

- `FreeRTOS 기반 멀티태스킹 시스템 구현` : 컨트롤러와 차량의 모든 제어기에 FreeRTOS를 적용하여, 센서 처리, 통신, 모터 제어 등 여러 작업을 안정적으로 동시에 처리하는 멀티태스킹 시스템을 구현한다.

- `합리적인 부품 구성을 통한 가격 경쟁력 확보` : 고가의 상용 부품 대신 널리 사용되는 가성비 모듈(STM32F103, nRF24L01 등)을 채택하여, 낮은 생산 단가로도 전문적인 제어 시스템을 구현할 수 있음을 증명한다.

본 작품은 단순한 RC카를 넘어, 미래 자동차 기술의 핵심 요소인 직관적 인터페이스, 차량 내 네트워크, 실시간 데이터 처리 기술을 소형 모델에 집약적으로 구현한다. 이는 취미 분야에 전문적인 제어 방식과 높은 수준의 현실감을 제공할 뿐만 아니라, 산업용 원격 제어 로봇이나 농기계 등 다양한 원격 제어 시스템에 적용 가능한 프로토타입으로서의 가치를 가질 것으로 예상된다.

🔩 보드 및 부품 선정

본 프로젝트의 모든 제어 유닛(컨트롤러 1개, 차량 내부 3개)의 MCU는 STM32F103C8T6로 통일하여 개발 환경의 일관성과 효율성을 확보하였다.

STM32F103C8T6는 ARM Cortex-M3 코어를 기반으로 72MHz의 충분한 클럭 속도를 제공하여 각 노드의 요구사항을 안정적으로 처리할 수 있다. 컨트롤러에서는 IMU 센서 데이터 처리 및 RF 통신을 담당하고, 차량 내에서는 메인 제어, 센서 데이터 처리, 모터 구동 등 각자 분담된 역할을 수행한다. 
특히 하드웨어적으로 CAN 컨트롤러를 내장하고 있어 별도의 컨트롤러 없이 CAN 트랜시버 모듈(MCP2551)만으로 안정적인 차량 내 네트워크를 구성할 수 있다. 또한 FreeRTOS를 구동하기에 충분한 성능을 갖추고 있으면서도 가격 경쟁력이 뛰어나, 본 프로젝트의 분산 제어 시스템 컨셉에 가장 적합한 MCU이다.

< 컨트롤러 (조종기) 부 >
- MCU: STM32F103C8T6
- 모션 센서: MPU6050 (6축 IMU 센서)
- 무선 통신: nRF24L01 (2.4GHz RF 송수신 모듈)
- 사용자 입력: 푸시 버튼 (엑셀/브레이크), 토글 스위치 (전/후진)
- 사용자 피드백: 햅틱 모터 (차량 상태 피드백)
- 디스플레이: SSD1306 (1.3인치 OLED)
- 18650 리튬 배터리(2s)

< 차량 부 (RC카) >
- 차량 섀시 키트
- MCU: STM32F103C8T6 (메인 제어부, 센서부, 디스플레이부 - 총 3개 사용)
- 무선 통신: nRF24L01 (2.4GHz RF 송수신 모듈)
- CAN 통신: MCP2551 (CAN 트랜시버 모듈)
- DC모터 : JGA25-370
- 모터 드라이버: L298N
- 서보모터 : MG996R
- 초음파 센서: HC-SR04
- 조도 센서 : LM393 ldr
- 기타: LED, 18650 리튬 배터리(3s), XL4015 DC-DC 스텝다운 컨버터, 저항, 로커 스위치

# ST-LINK 연결 문제 해결

---

## 문제 상황 (Problem)

1.  **`fail.txt` 파일에 아래와 같은 오류 메시지 발생:**
    ```
    The interface firmware FAILED to reset/halt the target MCU
    ```

2.  **ST-LINK Utility에서 `Target > Connect` 시도 시 에러 발생:**
    ```
    Can not connect to target!
    ```

3.  **전원 LED는 정상적으로 점등됨** (하드웨어 쇼트는 아닌 것으로 추정).

> 위와 같은 문제는 칩에 프로그래밍된 코드가 ST-LINK의 디버깅 인터페이스(SWD/JTAG) 핀을 다른 용도로 사용하거나, 칩을 저전력 모드로 즉시 전환시켜 연결을 방해할 때 주로 발생한다.

---

## 해결법 (Solution): BOOT0 핀을 이용한 부트로더 모드 진입

MCU가 사용자의 코드를 실행하지 않고 내장된 시스템 부트로더로 바로 진입하도록 하여, ST-LINK가 안정적으로 연결될 수 있는 환경을 만들어 준다.

### 단계별 절차

1.  **전원 완전 분리**
    * 보드에 연결된 ST-LINK와 전원 케이블을 모두 제거한다.

2.  **BOOT0 핀 설정 변경**
    * 보드에 있는 **BOOT0 핀을 3.3V(VDD)에 연결**한다. (점퍼를 옮기거나, 와이어를 이용해 직접 연결)
    * **BOOT1 핀은 0V(GND)에 연결**된 상태를 유지한다.
    

3.  **전원 재연결**
    * BOOT0 핀이 3.3V에 연결된 상태에서 보드에 전원을 다시 인가한다.
    * 이제 MCU는 사용자가 작성한 코드가 아닌 내장된 시스템 부트로더로 실행된다.

4.  **ST-LINK Utility 연결**
    * ST-LINK Utility를 실행하고 `Target > Connect`를 클릭한다.
    * 정상적으로 연결되면 칩의 정보가 표시된다.

5.  **칩 전체 메모리 삭제**
    * 연결 성공 후, 상단 메뉴에서 `Target > Erase Chip`을 선택하여 칩의 전체 내용을 삭제한다.
    * "Erase memory performed successfully" 메시지를 확인한다.

6.  **원상 복구**
    * 작업이 완료되면 보드 전원을 다시 분리한다.
    * **BOOT0 핀을 원래 상태(GND에 연결)로 되돌려 놓는다.**

    * 이제 다시 전원을 연결하고 정상적으로 펌웨어를 다운로드하거나 디버깅을 시작할 수 있다.
